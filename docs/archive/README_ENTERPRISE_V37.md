# MoonXprojecT Enterprise V37

## Executive UI & Dashboard Upgrade

V37 continues from V35/V36 and focuses on the executive HR command center while preserving the existing Supabase schema and modules.

### Included
- Executive HR Command Center dashboard
- Workforce composition by department
- Attendance Health visualization
- Live attendance feed
- HR process shortcuts
- Enterprise navy/gold visual hierarchy
- Responsive dashboard layouts
- Starter Vite App.css removed
- Package version 37.0.0

### Important
This release is a UI-focused iteration. Existing database migrations are preserved. Run `npm ci` and `npm run build` in a network-enabled development environment before production deployment.
