# MoonXprojecT Enterprise V23

## Indonesia Payroll Compliance Engine

V23 extends V22 with a production-oriented foundation for Indonesian statutory payroll:

- configurable statutory rule registry
- BPJS rule/cap metadata
- PPh 21 / TER rule registry
- annual PPh 21 reconciliation table
- immutable-style payroll statutory snapshots
- payroll statutory preflight RPC
- permission catalog for statutory review
- admin view for statutory rules

### Important
This is an engineering foundation, not legal advice. Indonesian payroll/tax rates, wage ceilings, TER tables, PTKP, BPJS rules, THR treatment, and annual reconciliation must be validated against the current official regulations before production use.
